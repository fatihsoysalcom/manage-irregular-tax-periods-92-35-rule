# Manage Irregular Tax Periods 92.35 Rule

This example demonstrates how to manage income across irregular tax periods and apply special rules, similar to using SUMIFS in a spreadsheet. It calculates total income for custom date ranges and then applies a hypothetical '92.35% rule' as a final adjustment to the annual total. This helps in understanding complex tax calculations for freelancers or professionals with non-standard reporting periods.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
